# My Round

A mobile-first PWA for taking drink orders at the pub. Build a round by tapping drinks, save your regulars and their favourites, and review order history.

**Live:** https://myround.netlify.app

## Features

- **Quick round building** — Tap drinks to add them to the current round
- **Saved regulars** — Store your friends and their usual orders
- **Favourites** — One-tap ordering for people's regular drinks
- **Order history** — Review past rounds
- **Mobile-first** — Designed for use at the bar on your phone
- **PWA** — Installable, works offline

## Tech Stack

- Vite + React + TypeScript
- react-router-dom
- vite-plugin-pwa + Workbox (service worker)
- Deployed on Netlify

## Development

```bash
npm install
npm run dev        # Start dev server
npm run build      # Production build
npm run preview    # Preview production build
```

## Deployment

Deployed on Netlify. Auto-deploys from main branch.
